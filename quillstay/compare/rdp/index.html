QuillStay vs Resort Data Processing (RDP / IRM)

RDP (Resort Data Processing) is a long-standing PMS and booking engine, widely used by condo-hotels and resorts, built on older Windows-based (RDPWin) technology with a web-based booking module (IRM/IRMng).
