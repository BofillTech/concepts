# Masterpiece Charters — image manifest

No images are stored locally in this folder. Every photo in the concept is a
**real** Masterpiece photo hotlinked from one of two live sources, with
`referrerpolicy="no-referrer"`. The sandbox that built this concept is
firewalled from both hosts, so they render blank in build QA but load normally
in a browser and on GitHub Pages.

Re-host all of them (e.g. `wp_upload_media` to bofilltech.com, or download into
this folder) before any client-facing or production use.
