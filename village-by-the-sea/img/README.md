# Village by the Sea — image manifest

Every photo on this concept is a **real Village by the Sea photo**, hotlinked from the
property's own Duda CDN (`lirp.cdn-website.com/3a752016/...`) with
`referrerpolicy="no-referrer"`. Nothing is stock and nothing is AI-generated.

The sandbox is firewalled from `lirp.cdn-website.com`, so photos render blank in build QA
but load normally live and on GitHub Pages.

For the WordPress build, re-host each of these via `wp_upload_media` and swap the `src`
values (or drop the files into this folder and use relative paths).
